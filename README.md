# Free Block Party Starter Pack

Free, printable, beginner-friendly printables for hosting a neighborhood block party — brought to you by [Asdale Dynamics, LLC](https://dylanasdale.github.io).

Flyers, sign-up sheets, potluck table cards, name tags, a kid-games guide, cleanup sign-ups, a rainy-day plan B, and a gentle organizer page about permits, quiet schedules, and different diets.

**No tracking. No accounts. No data collection.** Everything runs locally in your browser; nothing you type is sent anywhere.

## What's in the pack

Open `index.html` in any browser — it's the one-page home base with links to every printable.

| Printable | File | What it's for |
|---|---|---|
| Home index | `index.html` | One-page overview with links to all printables |
| Flyer | `printables/flyer.html` | One-page invite for doors, poles, and community boards |
| Potluck sign-up sheet | `printables/potluck-signup.html` | Organize mains, sides, desserts, and drinks |
| Cleanup sign-up sheet | `printables/cleanup-signup.html` | 15-minute cleanup shifts (thank the morning crew) |
| Potluck table cards | `printables/table-cards.html` | Allergen/diet labels: gluten, nuts, vegetarian, vegan, dairy-free, spicy, custom |
| Name tags | `printables/name-tags.html` | Twelve per page; type names or handwrite on party day |
| Kid games guide | `printables/kid-games.html` | Five low-cost games, one page of instructions |
| Rainy-day plan B | `printables/rainy-day-plan.html` | What to do for drizzle, steady rain, thunder, heat, wind |
| Kind reminders (organizer) | `printables/organizer-reminders.html` | Permits, quiet neighbors, schedules, diets, safety basics |

## How to use it

1. Open `index.html` (double-click, or run a local server if you prefer — see below).
2. Click a printable, then click any dotted blank and type your details.
3. Press the **Print** button (or Ctrl/Cmd+P). Blanks you didn't fill print as dotted lines you can fill with a pen.
4. Use plain 8.5×11 paper; name tags work best on card stock or sticker paper.

### Run a local server (optional)

The pages work by double-click alone. If you like serving files properly:

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```
